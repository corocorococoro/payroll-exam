# 問題コンテンツのレビュー運用

## 公開条件

問題は次をすべて満たした場合だけ学習・復習・模試に配信する。

- `review_status = approved` かつ `is_active = true`
- 正解・選択肢・解説を含む `content_hash` と `reviewed_content_hash` が一致
- 独立した学習目的を表す `concept_key` がある
- その目的を行動として記述した `learning_objective` がある
- 想起・適用・境界判断・誤概念修正・手順・計算のいずれかを示す `variant_role` がある
- `study_tier` が `core` または `reinforcement` で、全学習トピックに少なくとも1問の合格コアがある
- 狙う誤概念が特定できる問題では `misconception_key` がある
- 根拠となる公的機関または試験主催者の `source_urls` がある
- `reviewed_at` と `review_due_at` が設定され、期限を過ぎていない

内容を変更すると版番号を上げ、公開停止の `in_review` に戻す。旧版を学習済みのユーザーは習熟状態を引き継がず、再承認後に即日復習する。同じ知識を別場面で確認する正当な派生は同じ `concept_key` にする。レッスンでは弱点・復習期限を最優先し、次に未出の合格コア、上積み演習の順に配信する。模試問題は採点前のレッスンに出さず、誤答・無回答を採点後の即日復習と弱点レッスンに反映する。開始済み模試は開始時スナップショットで採点し、旧版の解答で新版の習熟を更新しない。詳細は [question-design.md](question-design.md) を参照する。

## 追加してよい問題

- 出題範囲表の未充足論点
- 複数制度をまたぐ判断、資料表の参照、端数処理など、既存問題と異なる技能を測る実務ケース
- 典型的な誤解を識別できる、根拠のある選択肢
- 既存学習目標の別役割として、初見の場面でも知識を使えるか確認する問題

前置き、固有名詞、数値、選択肢順だけを変えた問題は追加しない。件数目標を置かず、1問ごとに「この問題でしか測れない能力」を説明できることを優先する。

表示時の選択肢は固定シードで決定的に再配置し、正解位置の偏りを問題バンク全体と模試の両方で監査する。正答と誤答選択肢別フィードバックも同じ対応で再ラベルするため、問いの意味は変えない。

## 定期運用

- 毎週月曜8時に `php artisan content:audit` を自動実行
- GitHub Actionsでも毎週月曜に全テスト、正本からのDB再構築、`content:audit --strict` を実行する
- Railway本番はマイグレーション・コンテンツ同期後に `php artisan content:audit --strict` を実行し、エラーまたは類似問題警告があるリリースを起動しない
- 本番の `content:sync` は `database/seeders/data` とシーダーのリリースハッシュが変わった場合だけ正本を同期する。同じリリースでの再起動は、管理画面で更新したレビュー日・期限・メモを上書きしない
- 法改正、料率・税額表の更新、公式テキスト年度切替時は該当問題を一括して `in_review` にする
- 2026年11月試験向け問題は、法令基準日の2026年9月1日経過後に公式テキストと主催者案内で再レビューする
- 監査は期限切れ、未承認の内容変更、根拠不足、同一問題、学習目標の不整合、正解位置の偏り、公開模試の構成違反・セット間重複・模試内論点重複・単元偏りを検出する
- 公開模試は40問・120分・知識35問×2点・計算5問×6点・全問四肢択一を必須とする
- 各模試は全5単元を含み、各単元3〜14問、模試内の論点重複なし、公開模試間の問題重複なしを必須とする

合格圏は、各模試の初回受験が120分モードで、採点前に採用問題へ触れていない受験だけを対象とする。別の模試2回で各70点以上、平均80点以上、各回の計算18/30点以上、2回合算の全単元得点率60%以上を満たした場合だけ表示する。同一模試の再受験、90分圧縮モード、診断データが欠けた受験は判定へ含めない。

管理画面とインポートは、緊急停止、レビュー、次期リリース候補の確認に使う。問題本文や正答を恒久変更する場合は、管理画面だけで完結させず、唯一の正本である `question-bank.json` と必要な公式資料台帳を更新してテスト・レビューを通す。正本の変更を伴う次回リリースでは、DBを正本へ同期する。

## 難易度の扱い

難易度は公式公開例と比較し、単一知識の再生だけでなく、複数記述の正誤判断、制度横断、資料参照、時間制約下の計算を含むかをレビュー記録に残す。
