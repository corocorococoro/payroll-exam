# 問題コンテンツのレビュー運用

## 公開条件

問題は次をすべて満たした場合だけ学習・復習・模試に配信する。

- `review_status = approved` かつ `is_active = true`
- 正解・選択肢・解説を含む `content_hash` と `reviewed_content_hash` が一致
- 独立した学習目的を表す `concept_key` がある
- 根拠となる公的機関または試験主催者の `source_urls` がある
- `reviewed_at` と `review_due_at` が設定され、期限を過ぎていない

内容を変更すると版番号を上げ、公開停止の `in_review` に戻す。同じ知識を別場面で確認する正当な派生は同じ `concept_key` にし、1回のレッスンや模試に同時出題しない。

## 追加してよい問題

- 出題範囲表の未充足論点
- 複数制度をまたぐ判断、資料表の参照、端数処理など、既存問題と異なる技能を測る実務ケース
- 典型的な誤解を識別できる、根拠のある選択肢

前置き、固有名詞、数値、選択肢順だけを変えた問題は追加しない。件数目標を置かず、1問ごとに「この問題でしか測れない能力」を説明できることを優先する。

## 定期運用

- 毎週月曜8時に `php artisan content:audit` を自動実行
- 法改正、料率・税額表の更新、公式テキスト年度切替時は該当問題を一括して `in_review` にする
- 2026年11月試験向け問題は、法令基準日の2026年9月1日経過後に公式テキストと主催者案内で再レビューする
- 監査は期限切れ、未承認の内容変更、根拠不足、同一・類似問題、公開模試の構成違反を検出する
- 公開模試は40問・120分・知識35問×2点・計算5問×6点・全問四肢択一を必須とする

## 難易度の扱い

公式は最新の本試験問題と分野別配点を公開していないため、「本番同等」を断定しない。公式公開例と比較し、単一知識の再生だけでなく、複数記述の正誤判断、制度横断、資料参照、時間制約下の計算を含むかをレビュー記録に残す。
