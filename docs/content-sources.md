# 2026年度コンテンツの根拠と品質境界

最終確認日: 2026-08-09

このアプリは、給与計算実務能力検定2級の学習支援を目的とする。公式問題の転載ではなく、公表された出題範囲と公的機関の一次資料を基に作成したオリジナル問題である。受験時は当年度の公式テキストと受験案内を優先する。

## 問題構成と品質境界

- 公開48問: 一次資料に照らして個別作成した診断模試・発展問題
- 公開模試1セット: 40問・120分・100点・全問四肢択一（知識35問、計算5問）という公式公開仕様に合わせたオリジナル問題
- 公開停止300問: 少数の原型に前置き、数値、選択肢順だけを変えた問題だったため、学習上の独立性がないと判断して廃止
- 公開停止2模試: 上記生成問題を使用し、計算問題が数値入力で公式の四肢択一と一致しなかったため廃止

公式公開例には、複数の記述から正誤を判断する実務寄りの問題が含まれる。現行48問は基礎確認寄りの問題も多いため、**本番と同等の難易度を保証するものではない**。今後は出題範囲表の未充足箇所と、公式公開例に見られる複合判断・資料参照・実務計算を優先して追加する。

自動監査は、内容ハッシュと承認版の一致、一次資料URL、レビュー期限、同一・類似問題、模試の問題数・配点・四肢択一・知識/計算区分を検証する。計算式を持つ問題は正答の再計算も行う。ただし、本試験での出題や難易度は保証できない。法令基準日後は2026年度公式テキストと主催者案内を優先して再レビューする。運用手順は [content-review-policy.md](content-review-policy.md) を参照。
