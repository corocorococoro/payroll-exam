# 2026年度コンテンツの根拠と品質境界

最終確認日: 2026-08-09

このアプリは、給与計算実務能力検定2級の学習支援を目的とする。公式問題の転載ではなく、公表された出題範囲と公的機関の一次資料を基に作成したオリジナル問題である。受験時は当年度の公式テキストと受験案内を優先する。

## 試験仕様

- 職業技能振興会「給与計算実務能力検定 2級」: https://fos.or.jp/shikaku/pc2/
  - 40問、120分、知識35問×2点、計算5問×6点、合格基準70%以上
  - 11月試験は同年9月1日時点の法令等を基準とする
- 実務能力開発支援協会 2026年度試験日程: https://jitsumu-up.jp/news/2026/04/30/65107/
  - 2026年11月22日実施予定

## 問題構成と品質境界

- 48問: 一次資料に照らして個別作成した本番形式・発展問題
- 260問: 31の中核ルールを複数の業務場面で反復する定着問題。260個の独立論点という意味ではない
- 40問: 入力値を変えた実務計算問題。`calc_params` から正答を再計算する自動テストを持つ
- 模試3セット: 各40問・100点（知識35問、計算5問）

自動テストは、選択肢と正解キーの整合、解説・典型ミスの存在、計算式と正答の一致、模試の問題数・配点を検証する。ただし、法改正後の公式テキストへの反映方針や本試験での出題を保証するものではない。法令基準日後の変更がある場合は、公式テキストと主催者の案内を優先する。
