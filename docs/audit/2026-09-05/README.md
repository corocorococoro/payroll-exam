## 主な修正と横断確認

- **正答・複数正解・条件不足**：月額表の扶養2人を3,100円から3,090円へ訂正。法定「最低」と任意の有利な扱い、資格日と控除月、日数・年齢の境界、労使折半の重複肢を整理。本文の前提と誤答理由も一緒に修正した。[国税庁2026年原表](https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2026/data/all.pdf)
- **資料**：年休の通常・比例付与、通勤の全距離区分と2026年加算、雇用保険3業種を収録。賞与表を1例から甲0〜7人以上・21率と乙5区分へ拡充。拡張時の32セル誤読を独立抽出と画像照合で検出・訂正し、全セル回帰を追加した。[訂正前後](bonus-table-cell-corrections.json)
- **等級・総合計算**：健康50等級・厚年32等級と上下端の表を追加。50行×5列を原本から独立復号して250セル一致。模試734を等級表の選択を伴う形に、通常830・模試829を保険料と税額表から手取りまで求める形に改訂した。830は非課税通勤・介護・住民税を含み、829は介護なし・扶養1人。[総合計算の改訂記録](integrated-net-revisions.json)
- **レッスン**：15本の導入説明を整備。混在平均賃金の最低保障へ月給部分を加え、原則5,333.33円と最低保障8,000円の比較例に修正。社会保険の制度・用語・加入・報酬・年金・等級を6段落で補った。教材・表変更に依存する177件、その後の社会保険説明に依存する53件を再確認（重複を含む）。[前者](lesson-table-rechecks.json) / [後者](social-lesson-rechecks.json)
- **通常コアと統合**：当初通常コアがない6論点に既存2問と新規4問を配置。誤分類も訂正し、年度更新の通常コアを684へ変更。通常・模試の同じ想起を問う493・501・544・577を、2条件・具体日付を使う適用判断へ改訂した。[4問の記録](mock-cross-revisions.json)
- **範囲整理**：前月給与なし等の賞与特例、遡り昇給等の詳細を2級必須とする根拠が不足する15問を退役。模試395は新規837へ差し替え、枠と配点を維持。古い無条件の復興税期間暗記444も退役。法律上の正誤と級別の採用根拠を分ける。
- **模試の初見性**：正解位置の4問周期を解消し、正答・誤答説明の対応をテスト。資料内に同じ計算の答えがある567は金額を変更。文面候補8組はすべて現行指紋に一致する個別判断あり。ただし意味上の類似を完全に拾った保証や実測難易度の同等性はない。

主催者の公開給与計算例は、通勤の課税区分から保険料・税額表・差引支給までの連続操作を求める。改訂830・829はこの要求操作を練習する。公開例は2018年の条件で正答非掲載のため、2026年の数値検算には使用していない。[主催者の出題例](https://jitsumu-up.jp/about/)

## 検証結果と境界

**最終全体回帰166件成功、3件スキップ、6,347アサーション。** スキップは無効な二要素認証に依存する既存テスト。PHPStan（1GB）、型検査、ESLint、ビルド、変更PHPの書式検査も成功。全体回帰後の変更は監査報告のみ。途中の検出・失敗・修正はchecks.jsonに記録した。

テストDBはSQLiteメモリDB。アプリの動作検証ではテスト専用の架空承認を注入しており、実教材の公開承認ではない。実台帳のDB非使用監査では個別不一致0、全体承認保留1件で終了コード1になる。

計算は構造化21件と追加固定期待値21件を照合し、現行41問・退役旧問1問を区別。本文等から広めに抽出した104候補には制度・式の判断も含む。既に正答を見た問題を後から盲検したとは報告しない。829・830の検算器は最終差引段階であり、保険料・税額表の途中値は別途独立照合した。

PC1280×900とモバイル390×844で、長文レッスン、年休・賞与・等級・税表、模試ナビゲーションと結果を確認。表の行・列見出しと閉じるボタンを固定し、長表の高さを制限した。830では3資料を参照して解答選択まで操作。隔離DBから生成した静的HTMLのため、保存・採点はHTTP回帰で確認した。実端末の全837問の画面確認や初心者による効果測定ではない。

## 保留事項と次の完了条件

1. **公式本文・正誤表**：受領PDFは非公式予想問題集。ユーザーは公式テキストを所有していない。2026年の章内の全節・改正掲載範囲・求める深さとの照合は未実施。公式公開28項目への対応だけで必須範囲の合格判定は出さない。
2. **資料参照の不足**：月額表は3金額帯・甲0〜2人に限る。月額乙欄・日額表の金額演習、全国現物価額を使う換算、年度更新申告書全体の演習が不足。通常賞与・業種別料率の資料は増やしたが、十分な演習量の実証はない。詳しくは28項目の対応表。
3. **模試の構成と初見性**：5計算枠の操作数には差があり、模試2は部分計算が多い。操作表に明示したが、初回受験者の正答率・時間・識別力がなく、難易度の等価性は未検証。意味上の全重複の排除は保証しない。
4. **学習効果**：用語説明と導線は改善し再現テストを通した。アプリ中心で学んだ初心者が初見へ転移できるか、同日反復・復習滞留の長期影響、合格目安の妥当性は学習者による測定が必要。
5. **公開前**：上記の必須範囲を確認し、必要な追加・改訂問題にも同じ個別監査を行う。根拠を揃えて全体承認した後、隔離DBで実承認を使った同期と厳格監査を実施する。現時点では承認を迂回しない。

本番反映、実DBのマイグレーション・再構築・再シードは未実施。個別監査・実装の成功を、計画全体の完了や実測済みの合格効果とは報告しない。
