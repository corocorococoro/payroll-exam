# 問題バンク設計

最終更新: 2026-08-31

## 目的

件数を維持することではなく、給与計算実務能力検定2級の合格に必要な知識・境界判断・手順・計算を、重複なく繰り返し学べる問題バンクを維持する。

`database/seeders/data/question-bank.json` が全問題の唯一の正本である。旧問題と追加問題を別ファイル・別ID・別出題経路に分けない。2026年8月31日の統合時には、890問から学習上の差がない59問を退役し、831問・112学習トピックへ再編した。件数は目標値ではなく、追加・統合・削除の結果として変わってよい。

公式資料の表示名とURLは `database/seeders/data/official-sources.json` だけで管理する。問題は `source_keys` で台帳を参照し、SeederがURLへ解決する。模試は正本の `id` を `question_id` として参照する。

## 正本の構造

- `release`: 法令基準日、レビュー日、期限、宣言問題数、合格コア数、退役重複数
- `topics`: 学習トピックキーと「何ができるようになるか」の対応
- `questions`: 連番ID、トピック、役割、学習優先度、公式資料キー、問題本文、正答、解説、計算情報

Seederは宣言問題数と実数、トピック・資料キー、問題形式、正答を検証する。不一致があればDBへ不完全な問題バンクを投入しない。正本から消えた問題は再シード時に退役させる。

## 類似問題を残す基準

同じトピック内でも、測っている判断が次のように異なる場合は意味のある類題として残す。

- `recall`: 原則・定義を正確に想起する
- `application`: 具体的な給与・勤怠ケースへ適用する
- `boundary`: 「以上／超える」、年齢、日数など境界条件を判断する
- `misconception`: 制度間の混同など典型的な誤りを見抜く
- `workflow`: 届出・徴収・年度更新など処理順序を判断する
- `calculation`: 資料や端数処理を用いて金額を算出する

前置き、人物名、数値、選択肢順だけを変え、同じ手掛かりで正答できる問題は統合または削除する。トピックごとの最低問数や役割の一意性を機械的に要求しない。必要な反復数は論点の重要度・誤りやすさ・計算手順の多さで決める。

## 合格ファーストの配信

全問は一つの正本と一つの出題経路に置く。別問題バンクに分けず、問題ごとの `study_tier` で「合格コア」と「上積み演習」を表す。2026年8月31日時点は、公開模試の全採用問と各112トピックの代表問を含む289問が合格コア、残り542問が上積み演習である。この数は固定目標ではなく、模試構成や学習目標の変更に合わせて見直す。

レッスンは最大10問とし、「誤答または期限到来」→「未出の合格コア」→「未出の上積み演習」→「未定着」の順で出す。全問出題後は最後に解いた時刻が古い問題から再出題し、全問へ有限回で到達できる状態も保つ。模試の誤答と無回答は即日復習へ送り、弱点レッスンへ直接戻せる。

各レッスンは開始前に「なぜ学ぶか」「できるようになること」「要点」「よくある間違い」を示す。推奨順序は保つが、模試後の弱点補強を妨げないよう、レッスン自体は最初から直接開ける。

全問で正答と全体解説を表示する。典型的な誤答を個別に説明できる問題は `distractor_feedback` を持つ。`misconception_key` は狙いを特定できる問題だけに付け、空であることを品質違反にはしない。

## 教材取り込み

`scripts/extract_exam_202608.py` は受領PDFから問題・選択肢・正答・解説を検査付きで抽出する補助ツールであり、出力自体は正本ではない。PDFは `.gitignore` と `.dockerignore` の対象で、リポジトリへ追加しない。抽出結果を正本へ採用するときは、既存トピックへの割当て、重複判定、公式資料照合、法令補正を行う。

## 更新手順

1. 主催者の出題範囲と公的機関の一次資料を確認する。
2. `question-bank.json` のトピック・問題と、必要なら `official-sources.json` を更新する。
3. 同一判断を測る既存問題との重複と、模試参照への影響を確認する。
4. `php artisan migrate:fresh --seed` で正本からDBを再構築する。
5. `php artisan content:audit --strict` と全テストを通す。
6. 法令基準日、公式テキスト、料率・税額表の更新時に該当トピックを再レビューする。
